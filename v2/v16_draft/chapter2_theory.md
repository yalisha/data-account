## 2.1 数据资源的表外性与估值不确定性

资源基础观为理解数据要素的价值创造提供了微观基础。按照 Barney（1991）与 Zollo 和 Winter（2002）的经典界定，异质性的生产资源通过生产、决策、风险管理等业务路径影响企业未来现金流，进而转化为可识别的企业价值。数据要素作为新型战略资源，既具有资本与人力要素不具备的非竞争性与可复用性，又能够与原有生产要素融合产生乘数效应，这一特性在中国数字经济文献中已有大量梳理（王永钦，2021；张新民等，2023）。

然而，与资本、人力、自然资源等传统生产要素不同，企业的数据资源长期游离于财务报表之外。2024 年财政部发布《企业数据资源相关会计处理暂行规定》之前，企业对数据的投入、持有与利用均未在资产负债表中得到系统反映，投资者难以像识别存货或无形资产那样识别企业的数据要素存量与使用效率。这种表外化并非单纯的会计处理问题，而是根植于数据资源的不可验证性与难估值性——数据缺乏统一的权属界定、质量评估标准与市场化定价基准（徐宗本等，2022；陆岷峰，2023）。

数据资源的这种非传统属性为投资者带来严重的估值不确定性。Merton（1987）的 investor recognition 模型指出，当投资者缺乏对某类资产的完整信息时，其估值会偏离其基本面价值并产生定价摩擦。Amihud 和 Mendelson（1986）则从信息不对称的交易成本视角论证，投资者需要对信息弱势资产要求更高的风险溢价。Barron 等（1998）进一步将估值不确定性分解为共同信息不确定性与特质信息不确定性两个维度，并指出前者更容易通过披露改善。Akerlof（1970）经典的"柠檬市场"论证也揭示：当资产价值无法外部验证时，优质资产反而会被逆向选择淘汰——这正是数据资源若长期保持不可见状态时最容易发生的市场失灵。

综上，资源基础观揭示了数据要素对未来现金流的积极意义，但信息经济学框架也同时指出：当数据资源在资产负债表上缺席、在业务描述中模糊时，投资者难以将其映射为可定价的企业价值。**年报披露成为缓解这一估值不确定性的关键——也是唯一——制度性窗口**。

## 2.2 从数据要素到披露：三层概念界定

在进入披露的定价效应分析之前，有必要对本文涉及的三层相关但截然不同的概念进行严格区分，这对后续的识别策略与理论映射至关重要。

**第一层：数据要素（data as factor）**。指企业在生产经营中形成或获取、可用于创造价值的数据资源，作为与资本、劳动、土地、技术并列的新型生产要素（国务院《关于构建更加完善的要素市场化配置体制机制的意见》，2020）。数据要素的特征是非竞争性、可复用性与规模报酬递增（Jones 与 Tonetti，2020）。它是一种客观存在的企业资源，与企业是否"对外说"无关。

**第二层：数据要素利用（data utilization）**。指企业将数据资源投入实际经营决策、产品创新、流程优化或风险管理的行为过程。这是一种经营行为，发生在企业内部。数据利用的效率与深度决定了数据要素能否转化为真实现金流。

**第三层：数据要素利用披露（data-element utilization disclosure）**。指企业通过年度报告等法定信息披露渠道向外部投资者传递其数据利用状况的信息行为。这是一种信息行为，由企业选择呈现于公共文本。

三层之间的关系是：数据要素提供资源基础，数据要素利用将资源转化为现金流，数据要素利用披露则将前两层的存在与质量向资本市场传递。前两层主要在企业内部发生并且对外部投资者不可观测；后一层则直接进入资本市场的定价函数。

这一区分对本文识别策略至关重要。本文的自变量——DU<sub>kw</sub>、DU<sub>llm</sub> 及其质量指标——测量的是年报文本层面的披露行为，而非底层数据能力本身。这一聚焦在理论上符合 Merton（1987）与 Verrecchia（2001）的基本设定：定价效应通过信息触达投资者起作用，能力本身若不进入投资者信息集则不产生定价后果。在识别上，本文后文将通过两条路径分离"披露维度"与"能力维度"：一是借助同行业跨省 peer 均值与省级数字化指数两个外生工具变量（第四章），二是借助披露质量指标（DU<sub>closedloop</sub>、DU<sub>llm,lenstd</sub>、WashGap 等）——两个数据能力接近的企业若在披露质量上存在差异且对应不同定价效应，这一差异只能归因于信息维度（见 H2b、H2c）。

综上，本文的核心研究对象是第三层——**数据要素利用披露**。这一界定将在全文（除背景性讨论外）严格保持，避免与第一、二层概念的滑动。

## 2.3 披露为何能缓解估值不确定性

信息披露缓解估值不确定性的机制在理论与实证文献中已形成较为清晰的逻辑链条。Grossman 和 Stiglitz（1980）建立的理性预期均衡模型指出，披露将私人信息转化为公共信息，降低投资者之间的信息不对称程度，促进价格发现；Verrecchia（2001）对自愿披露文献的综述进一步明确，披露提高价格对基本面的反应速度，同时降低 bid-ask spread 与股价延迟。Dye（1985）以及 Welker（1995）则从交易成本视角论证，提高披露透明度能够缩小买卖价差并降低流动性风险溢价。Hou 和 Moskowitz（2005）提出的股价延迟（PriceDelay）测度正是对上述机制的直接实证操作化——股价延迟越低，意味着市场越快将新信息融入价格，定价效率越高。

从披露效应的制度背景看，中国资本市场既有强制披露框架（证监会《公开发行证券的公司信息披露内容与格式准则》）也有自愿披露空间（MD&A 等非标准章节），数据要素利用披露主要处于后者。正因如此，自愿披露的动机、方式与实质性差异便成为影响定价效率改善程度的关键变量——Verrecchia（1983）的"门槛披露"模型与 Dye（1985）的"信号披露"模型对此分别提供了理论基础。

基于上述逻辑，本文提出第一条基础假说：

**假说 H1**：其他条件不变，企业数据要素利用披露程度越高，其股价定价效率越高，具体表现为股价延迟程度降低。

H1 不是本文的核心贡献——它只是接下来更精细分析的起点。本文真正关心的问题是：**同样是"披露了多少"的变化，不同披露内容与不同披露信息含量是否产生相同效果？** 这一问题将把文献从"披露—定价"的总量关系，推进到披露的内部结构与信息含量分析。

## 2.4 披露内容异质性：价值链视角

不同文献对"企业披露内容差异如何影响市场反应"给出了互补的证据。Merkley（2014）基于美国样本发现 R&D 相关披露内容的增加显著降低分析师预测分歧，但这一效应在不同披露类别之间差异明显；Dou 等（2023）通过文本分析进一步指出，年报中涉及业务操作与价值转化的段落比纯财务讨论具有更强的信息含量。这两个研究在测量方式上存在分歧：Merkley 依赖关键词字典识别披露内容类型，而 Dou 等采用机器学习方法分层文本主题。分歧的实质在于**如何界定"具有定价信息含量的披露"**——这是本文第一个要回应的问题。

本文将数据要素利用披露按价值链视角分解为五个环节：数据资源（stock）、数据开发（dev）、数据应用（app）、数据价值化（value）与数据治理（gov）。这一分解的理论依据是数据从资源形态向现金流转化的链条性——不同环节对未来现金流的映射距离不同。数据应用层和数据开发层直接对应业务收入或成本的改善路径，其披露内容最接近投资者关心的现金流问题；数据资源层则反映企业的潜在数据存量，是现金流的前置条件但尚未实现；数据价值化与数据治理层则处于价值链两端，前者对应货币化成果而后者对应制度基础。

沿价值链分阶段考察披露，也与中国数字经济文献关于数据要素资产化、产品化、市场化的"三化"过程讨论相衔接（张新民等，2023）。与已有研究将披露作为同质对象处理不同，本文允许不同价值链环节的披露产生差异化的定价效应。

由此提出：

**假说 H2a**：其他条件不变，企业数据要素利用披露中，越贴近现金流形成端的环节（数据应用、数据开发、数据资源）对股价定价效率的改善作用越显著；与价值链末端或制度基础层（数据价值化、数据治理）相关的披露由于现实中披露密度稀疏，其定价效应受限。

H2a 将披露按价值链环节拆分处理，而非以"披露多/披露少"的单一总量刻画，是本文对披露异质性研究的第一层推进。

## 2.5 披露信息含量差异：语义质量与模糊披露

即使披露了同样多的内容，其信息含量也可能差异巨大。这是本文要回应的第二个问题。文献在"如何识别高信息含量披露"这一问题上有两条主要研究路径。一条路径关注正向质量维度——Bushee 等（2018）以年报文本可读性指数衡量披露信息含量，发现高可读性披露对应更低的盈余公告 PEAD；Loughran 和 McDonald（2011）构建金融情感词典识别文本中的实质性语义，文本情感分析框架后被广泛应用于定价效率研究；Li（2008）从 Fog Index 角度测量年报复杂性，发现复杂年报对应较低的盈利持续性。另一条路径则从反面识别模糊披露——Bonsall 等（2017）证实披露模糊性加剧分析师预测分歧并延迟信息反映；Bourveau 等（2020）用漂绿指标识别可持续性披露中的概念堆砌，发现这类披露不仅未能缩小估值不确定性，反而加剧投资者分歧。

两条路径的理论共识是：披露的定价价值并非取决于"说了多少"，而取决于"说了什么"与"怎么说"——前者已由 H2a 回应，后者需要专门的质量测度。本文采用五个互补的披露质量代理变量构建 convergent validity：闭环披露（DU<sub>closedloop</sub>）识别披露是否呈现从资源到价值的完整链条；核心业务嵌入（DU<sub>core</sub>）识别数据披露是否落在企业主营业务文本范围；链条完整性（DU<sub>chain,count</sub>）对五个价值链环节的覆盖广度进行加总；MD&A 嵌入（DU<sub>kw,mda</sub>）识别数据披露是否出现在管理层讨论与分析的实质性经营讨论章节；语义×密度复合指标（DU<sub>llm,lenstd</sub>）将 LLM 语义评分与关键词密度结合，捕捉披露的语义加权强度。

五个代理变量分别从结构、主题、广度、章节、语义五个角度切入同一个构念——披露的信息含量。这样并行设计既呼应 Loughran 和 McDonald（2020）文本分析综述中"单一指标容易被噪声污染"的警示，也为后文的联合回归提供识别基础：如果某一指标与披露密度 DU<sub>kw</sub> 高度相关而在联合回归中失显著，那是 convergent validity 的证据而非缺陷。

**假说 H2b**：其他条件不变，企业数据要素利用披露的闭环性、核心业务嵌入、链条完整性、MD&A 嵌入、语义×密度复合指标分别独立降低股价延迟；在控制披露密度后，上述质量指标仍具有显著的增量解释力。

与 H2b 的正向质量相对，披露的模糊化与错配同样值得考察。当披露具备较高的广度（关键词覆盖面大）却缺乏对应的深度（缺少语义实质）时，披露便从信息供给滑向了信息模糊——这是"漂绿"文献所关心的核心现象。本文用 WashGap 测度这一现象：将披露密度（DU<sub>kw</sub>）的标准化值减去语义×密度复合指标（DU<sub>llm,lenstd</sub>）的标准化值，得到"广度减深度"的错配度量。WashGap 值越大，意味着企业披露广度超过其语义深度，表现出概念堆砌而非实质披露的特征。

**假说 H2c**：其他条件不变，数据要素利用披露中的广度-深度错配（WashGap）越严重，股价延迟越大，反映投资者面对概念化披露时估值不确定性不降反升。

H2b 与 H2c 共同构成本文对披露异质性研究的第二层推进——从"披露什么"（内容维度）进一步推进到"披露的信息含量如何"（质量维度）。

## 2.6 不确定性缓解的下游与情境

如果估值不确定性是数据要素披露影响股价定价效率的内在机制，那么与估值不确定性下降**相一致**的下游变量也应当呈现一致的变化方向。本文从三个维度考察：解释不确定性、基本面不确定性、价值实现不确定性。

解释不确定性维度的代表指标是分析师预测分歧（ForecastDisp）。Barron 等（1998）在经典的理性预期框架中指出，当信息公共化程度提高，分析师对未来盈利的预测将更趋一致，分歧收窄；随后的 Lang 和 Lundholm（1996）以及 Byard 等（2011）则实证验证自愿披露改善分析师共识。若数据要素披露有效降低投资者的估值不确定性，则分析师对披露企业未来盈利的解读应当更加一致。

基本面不确定性维度的代表指标是经营现金流的波动率（CashFlowVol）。Dichev 和 Tang（2009）证实企业盈利波动与估值不确定性之间存在稳健的正相关，而 Dechow 和 Dichev（2002）则从应计质量视角验证基本面可预测性与信息不对称的联系。若数据要素披露伴随真实的数据利用能力改善，则企业经营稳定性应当相应提升——这不是数据披露直接改变现金流，而是数据能力的可验证性提高缓解了投资者对基本面不确定性的担忧。

价值实现不确定性维度的代表指标是供应链集中度（SCConc）。Kulchania 和 Thomas（2017）指出供应链集中度高的企业面临更大的经营中断风险，而 Campello 和 Gao（2017）则证实高集中度企业在负向冲击下存在更大的定价摩擦。若数据披露反映企业借助数据能力构建更稳健的供应链结构，则披露企业应呈现较低的供应链集中度——这与估值不确定性中价值实现风险的下降一致。

基于三条路径的统一理论逻辑，本文提出：

**假说 H3**：数据要素利用披露通过与估值不确定性下降相一致的三条下游 channels——分析师预测分歧收窄、经营现金流波动降低、供应链集中度下降——影响股价定价效率。

需特别说明的是，本文识别的是**与估值不确定性下降相一致的下游表现**，而非严格意义上的 mediation 证据。遵循江艇（2022）在《中国工业经济》对中国经济学文献机制识别的讨论，本文通过 X → M 的独立显著关系建立 channels 一致性，不作基于 Baron-Kenny 或 Bootstrap 的正式中介检验。这一识别策略的局限将在结论部分讨论。

除了一致性下游证据，数据要素披露的定价效应在不同企业情境下应呈现可预测的异质性。本文提出一个统一框架：**当企业原始估值不确定性更高、市场信息处理摩擦更大、或外部监督更强时，数据要素披露的边际定价作用更强**。在这一框架下：政策时期（Post2020）反映信息摩擦随政策出台而变化——2020 年前数据要素尚未成为政策焦点，企业的数据披露在信号稀缺环境下具备更高定价价值；产业异质性（DigEconCore、HighTech）反映业务数据依赖度决定的基准不确定性——非数字经济核心产业与非高科技产业由于数据能力的先验认知度较低，其披露提供的增量信息更大；融资约束（SA）从外部信息价值角度放大披露效应——高融资约束企业的外部信息相对价值更高；机构持股（InstHold）反映外部监督与信息处理能力——高机构持股企业信息被有效消化的概率更大，披露的定价效应更强。

**假说 H4**：在原始估值不确定性更高（非数字核心、非高科技、高 SA 企业）、信息摩擦更大（2020 年前政策时期）、外部监督更强（高机构持股企业）的企业组，数据要素利用披露对股价定价效率的改善作用更强。

## 2.7 小结与贡献定位

本文的理论框架可概括为：数据资源的长期表外化带来投资者估值不确定性，年报披露是缓解这一不确定性的制度窗口。围绕这一主线，本文沿三个层面推进披露异质性研究：（一）从"披露多少"推进到"披露什么"——价值链视角下的内容异质性（H2a）；（二）从"披露什么"推进到"披露信息含量如何"——语义质量与模糊披露的双面识别（H2b、H2c）；（三）通过下游 channels 的一致性证据（H3）与情境异质性的统一框架（H4），建立披露与估值不确定性下降之间的理论映射。

与以往披露—定价文献相比，本文在两方面具有理论贡献。**第一**，将"信息供给效应"与"信息模糊效应"统一到估值不确定性框架下，避免将两者视为独立竞争性的理论——二者实为同一机制在不同披露质量条件下的不同结果。**第二**，在方法上沿价值链不同环节拆分披露内容，并辅以五个披露质量代理变量，为会计信息披露研究中"披露内容—信息含量"双维度分析提供经验基础。这两点共同回应了现有文献"披露数量研究"与"披露质量研究"长期分离的局限。
