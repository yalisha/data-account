# 自然人责任边界与企业风险披露质量：撞题初查

日期：2026-05-06

## 一、初步结论

截至本轮公开网页检索、本地 Scopus/CNKI 下载池关键词共联、已有个人破产文献综述结果，暂未发现直接研究：

```text
个人破产制度 / 个人债务集中清理
x 自然人责任暴露 / 自然人担保 / 控制人失败成本
-> 上市公司风险披露质量 / 风险披露具体性
```

这个方向不是“完全没有相邻文献”，而是相邻文献分散在三块：

1. 个人破产制度的企业后果：已有盈余平滑、信贷供给、创业活跃度等；
2. 风险披露质量：已有中国上市公司风险披露、MD&A 风险披露、政治关联、气候风险披露等；
3. 破产法 / 债权人权利与信息：已有 creditor rights、战略性披露、CDS 信息含量等。

但目前没有看到把三者合在一起的论文：个人破产制度作为自然人责任边界冲击，作用于企业风险披露质量。

## 三、公开网页与学术检索证据

### 1. 个人破产制度的制度含义支持自然人责任边界

国家层面改革文件明确把个人破产制度与企业破产产生的自然人连带责任担保债务相连。每经网转发国家发改委方案时写到，研究建立个人破产制度，重点解决企业破产产生的自然人连带责任担保债务问题，并明确自然人因担保等原因形成的生产经营相关负债可依法合理免责。

来源：

- https://www.nbd.com.cn/articles/2019-07-16/1354400.html
- https://m.cnr.cn/news/20190719/t20190719_524697368.html
- https://www.gov.cn/xinwen/2019-07/31/content_5417452.htm

这说明 `自然人责任边界` 不是硬造概念，而是政策文本本身支持的制度含义。

### 2. 风险披露质量文献已存在，但没有接个人破产制度

相邻文献包括：

- Elshandidy, Neri, and Guo：研究中国金融企业风险披露质量的决定因素和市场流动性后果；
- 风险披露与股价信息含量：研究中国上市公司风险披露是否提高价格信息含量；
- 政治关联与企业风险披露：使用中国 Regulation 18 冲击研究企业失去政治关联后的风险披露变化；
- 气候风险披露、供应链风险披露等新型风险披露文献。

这些文献说明 `风险披露质量` 本身是可发表的会计 / 披露 Y，但目前检索没有看到以个人破产制度或自然人责任边界作为 X。

代表来源：

- https://www.researchgate.net/publication/328345406_Determinants_and_impacts_of_risk_disclosure_quality_evidence_from_China
- https://www.sciencedirect.com/science/article/abs/pii/S1061951817300186
- https://www.tandfonline.com/doi/abs/10.1080/16081625.2025.2603322
- https://www.sciencedirect.com/science/article/pii/S1059056026001541

### 3. 债权人权利 / 破产法与信息披露存在英文相邻文献

最接近的英文相邻文献是 Hasan, Marra, Wu, and Zhang 的 `Creditor-Control Rights and the Nonsynchronicity of Global CDS Markets`。该文研究 creditor-control rights 对全球公司 CDS 非同步性的影响，并认为债务人为避免债权人干预存在战略性披露激励。

来源：

- https://academic.oup.com/rcfs/article-pdf/14/1/204/50128049/cfad010.pdf
- https://centaur.reading.ac.uk/111250/

这篇不是撞题，但提示了一个有用理论接口：

```text
债权人 / 债务人权利变化 -> 管理层战略性披露激励变化
```

我们的区别是：

```text
个人破产制度改变自然人保证人 / 控制人的责任边界
-> 上市公司风险披露质量
```

### 4. 自然人担保与上市公司披露是现实存在的披露对象

公开市场公告中，控股股东 / 董事提供 personal guarantee 给上市公司贷款并作为 connected transaction 或财务资助披露，是现实存在的场景。例如香港上市公司公告披露控股股东为公司贷款提供 personal guarantee，且说明其上市规则含义。

来源：

- https://ae.marketscreener.com/quote/stock/STAR-GROUP-ASIA-LIMITED-29689145/news/Star-Properties-Cayman-Islands-FINANCIAL-ASSISTANCE-FROM-CONTROLLING-SHAREHOLDER-25020447/

这不构成论文证据，但有助于说明自然人担保 / 控制人责任链条能够进入上市公司信息披露。

## 四、当前 novelty 判断

### 直接撞题风险：低

暂未发现：

```text
个人破产制度 -> 企业风险披露质量
个人破产制度 x 自然人责任暴露 -> 风险披露具体性
个人债务集中清理 x 自然人担保 -> 上市公司风险披露
personal bankruptcy x corporate risk disclosure
personal guarantee exposure x risk disclosure quality
```

### 相邻文献压力：中等

压力来自两边：

1. 个人破产制度已有企业会计后果，尤其盈余平滑；
2. 风险披露质量已有成熟文献，需要强调制度冲击和自然人责任边界，而不是只做普通披露决定因素。

### 最适合的贡献表述

不要写：

```text
个人破产制度影响企业风险披露
```

更好写：

```text
个人破产制度作为自然人责任边界冲击，
改变企业控制人 / 自然人担保人的失败成本和责任暴露，
进而影响上市公司风险披露的具体性、非模板化和坏消息透明度。
```

## 六、暂定结论

这个方向目前可以继续推进，优先级高于继续围绕崩盘风险或债务短期化修补。下一步关键不是再查有没有 `风险披露` 泛文献，而是确认两件事：

1. 能否构造足够硬的风险披露质量指标；
2. 能否构造自然人责任暴露，尤其自然人担保或控股股东 / 实控人责任暴露。

只要这两个变量能做硬，题目有继续价值。
