# 个人破产制度外部评审吸收记录

日期：2026-05-04

## 一、评审结论

外部评审与当前内部判断一致：

> 继续，但只能继续成“自然人责任边界冲击”题，不能继续成“个人破产制度影响企业某个 Y”题。

需要放弃的宽口径：

- `PB -> CrashRisk`
- `PB -> DebtMaturity`
- `PB -> Innovation`
- `PB -> AuditFee`

需要保留的窄口径：

```text
PB_city,t x NaturalPersonLiabilityExposure_i,pre
```

主线应是坏消息隐藏和信息风险，债务短期化作为信贷收缩边界机制。

## 二、吸收为研究设计 v2 的关键修改

1. 题目从“个人破产制度与股价崩盘风险”改为“自然人责任边界与企业坏消息隐藏”。

2. Crash risk 不再作为唯一主 Y，而是作为坏消息集中释放的资本市场后果。

3. X 的最高优先级改为自然人保证担保金额或 dummy：

```text
NPGuaranteeExposure_i,pre =
自然人为公司债务提供保证担保金额 / 有息债务
```

4. `natural_pre`、`failure_cost_pre` 只作为试跑代理和最低口径，不再作为理想口径。

5. `high_lev_pre` 不能单独解释为自然人责任暴露，只能作为债务依赖或信贷收缩暴露。

6. 主模型必须加入一版：

```text
ExposureGroup x YearFE
```

7. 标准误除城市/中院辖区聚类外，应补 wild cluster bootstrap 或随机化推断。

8. 下一步优先补自然人担保、股权质押、风险披露和审计文本，而不是继续裸跑更多 Y。

## 三、修订后的优先路线

第一优先级：

```text
PB x 自然人责任暴露 -> 坏消息隐藏/风险披露/会计稳健性 -> Crash risk
```

第二优先级：

```text
PB x 自然人保证/债务依赖 -> 债务短期化/融资滚动压力
```

第三优先级：

```text
PB x 失败成本暴露 -> 风险承担/创新
```

第三优先级暂不建议推进为主文。

## 四、硬门槛

如果出现以下情况，应降级或停止：

- 只有 `natural_pre` 显著，硬 X 不显著；
- 加入 `ExposureGroup x YearFE` 后主效应消失；
- `k = -2` 或 `k = -3` 前趋势显著且方向与政策后相同；
- SOE placebo 显著；
- 剔除深圳或疫情年份后结果消失；
- 无法获取自然人担保或至少股权质押数据。

如果出现以下情况，可以推进：

- `NPGuaranteeExposure` 或 `Pledge x NaturalController` 显著；
- 披露、稳健性、减值及时性与 NCSKEW/DUVOL 方向一致；
- 债务短期化机制在高自然人保证/高债务依赖企业中成立；
- SOE placebo 不显著；
- wild bootstrap 后仍稳。
