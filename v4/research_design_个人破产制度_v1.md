# 个人破产制度研究设计 v1

更新日期：2026-05-04

## 一、核心定位

本文不研究“个人破产制度是否影响企业”。这个问题太宽，也已经被相邻文献覆盖。

本文研究：

> 个人破产制度改变自然人责任边界后，企业背后的自然人控制人、自然人保证人和自然人股东是否改变其坏消息隐藏、风险累积和财务报告行为。

因此，核心不是城市层面的 `PB`，而是：

`PB_city,t x 自然人责任暴露_i,pre`

个人破产制度本身发生在城市/法院辖区层面，但制度真正作用的对象是自然人。企业受到影响，是因为企业背后的自然人承担或预期承担了企业失败后的个人债务、保证责任、信用惩戒和控制权损失。

## 二、论文暂定题目

首选：

> 自然人责任边界与企业坏消息隐藏：来自个人破产制度试点的证据

备选：

> 失败容错还是信贷收缩？个人破产制度与企业信息风险

不建议：

> 个人破产制度与股价崩盘风险

原因是陈怡欣、张俊瑞（2026）已经在《会计研究》中把个人破产制度和股价崩盘风险作为经济后果连接起来。本文必须从“自然人责任暴露”而不是“PB 平均效应”切入。

## 三、理论机制

### 机制一：失败容错降低坏消息隐藏

在个人破产制度缺位或个人债务清理机制不完善时，自然人控制人、实际控制人、创始人或自然人保证人面临较高失败成本。一旦企业经营恶化，企业失败可能传导为个人连带债务、信用惩戒、股权质押爆仓、控制权丧失和再创业受阻。

因此，高自然人责任暴露企业的控制人更可能：

- 延迟确认坏消息；
- 维持短期业绩和股价；
- 隐瞒经营风险；
- 通过会计或披露方式拖延风险释放；
- 在融资压力下继续强撑风险项目。

个人破产制度提供一定的债务清理、信用修复和重新开始预期，降低自然人失败后的毁灭性后果。对高自然人责任暴露企业而言，控制人隐藏坏消息和强撑股价的私人收益下降，企业信息风险降低。

预期：

`PB x 自然人责任暴露 -> 坏消息隐藏下降`

经验表现：

`PB x Exposure -> NCSKEW / DUVOL 下降`

### 机制二：追偿价值下降导致信贷收缩

个人破产制度也会降低自然人保证、自然人连带责任和个人追偿的事后价值。银行和债权人可能认为自然人责任保护垫变薄，从而调整贷款条件。

可能表现为：

- 贷款期限缩短；
- 短期债务占比上升；
- 信用贷款和保证贷款减少；
- 抵押、质押要求上升；
- 融资成本上升；
- 对高杠杆企业的滚动审查加强。

这条机制可能产生相反结果。对高杠杆或高度依赖自然人保证的企业，信贷收缩会加剧融资压力，进而诱发更强的坏消息隐藏、风险转移或真实经营扭曲。

预期：

`PB x 高债务/高自然人保证暴露 -> 债务短期化上升`

并且在这类企业中，PB 对坏消息隐藏的改善效应可能减弱，甚至反向。

## 四、研究假说

### H1：自然人责任边界与坏消息隐藏

个人破产制度实施后，自然人责任暴露越高的企业，坏消息隐藏程度越低。

对应模型：

`BadNewsHoarding_i,c,t = beta PB_c,t x NPExposure_i,pre + FE + Controls + epsilon`

预期：

`beta < 0`

如果 Y 是 `NCSKEW` 或 `DUVOL`，则系数应为负。

### H2：失败成本暴露的异质性

上述效应在自然人实控、民营、创始人控制、股权质押、个人担保和高控制权风险企业中更强。

预期：

`PB x NPExposure` 的负向效应主要来自自然人失败成本更高的企业。

### H3：信贷收缩的反向边界

个人破产制度降低自然人追偿价值后，高债务依赖或高自然人保证暴露企业的债务期限更短，融资滚动压力更高。

预期：

`PB x DebtExposure -> ShortDebtRatio 上升`

同时，高债务依赖企业中，PB 对坏消息隐藏的改善效应更弱，甚至可能转为风险上升。

### H4：治理和披露机制

如果 PB 的作用是降低坏消息隐藏，而不是简单改变股价波动，则应观察到：

- 会计稳健性增强；
- 坏消息确认更及时；
- 风险披露更具体；
- 审计师风险反应增强；
- 机会主义盈余管理下降。

这些结果可以作为机制和辅助证据，不必全部成为主 Y。

## 五、核心变量构造

### 1. 政策变量：PB_city,t

主变量：

`PB_city,t = 1`，如果城市 c 在年份 t 已经实施个人破产制度、个人债务集中清理或类个人破产试点。

主口径建议采用 narrow policy table：

- 只纳入城市/法院辖区已有明确制度文件、试点文件或正式运行的地区；
- 按生效日或实质运行年份编码；
- 如果政策在当年下半年或年底出台，主回归可以从下一年开始计入。

稳健性口径：

- formal PB：深圳、厦门等正式个人破产法规；
- debt clean-up：温州、浙江、杭州、东营等个人债务集中清理/类个人破产；
- first-case：按首例案件受理年份编码；
- month intensity：当年实施月份数 / 12。

### 2. 核心暴露度：自然人责任暴露

最理想口径：

`NPGuaranteeExposure_i,pre = 自然人为公司债务提供保证担保的金额 / 有息债务`

自然人包括：

- 实际控制人；
- 控股股东中的自然人；
- 法定代表人；
- 董事长、总经理、董监高；
- 自然人股东及其配偶、亲属；
- 企业经营者个人连带保证人。

可替代口径：

`NPGuaranteeDummy_i,pre = 1`，如果政策前企业存在自然人保证担保。

`ControllerExposure_i,pre = 1`，如果企业为自然人实控。

`FailureCostExposure_i,pre = 自然人实控 + 民营 + 创始人控制 + 股权质押 + 高杠杆 + 自然人担保`

当前试跑代理：

`natural_pre = 政策前是否自然人实控`

`failure_cost_pre = (private_pre + natural_pre + founder_pre + high_lev_pre) / 4`

`natural_highlev_pre = natural_pre x high_lev_pre`

正式论文中，`natural_pre` 和 `failure_cost_pre` 可以作为低成本代理，但最好补自然人担保或股权质押数据，否则 X 的经济含义不够硬。

### 3. 主结果变量：坏消息隐藏 / 信息风险

首选主 Y：

`NCSKEW`：负收益偏态，数值越大表示崩盘风险越高。

`DUVOL`：下行波动率相对上行波动率，数值越大表示崩盘风险越高。

论文写法不应把它们简单叫“股价崩盘风险”，而应表述为坏消息隐藏和风险集中释放的资本市场代理。

可补充 Y：

- Crash dummy；
- 极端负收益发生概率；
- 负面公告集中度；
- 风险披露语调和具体性；
- 会计稳健性；
- 资产减值和信用减值计提；
- 审计费用、非标意见、持续经营段落、关键审计事项。

### 4. 机制变量

信贷收缩机制：

- `short_liab_ratio = 流动负债 / 总负债`；
- 短期借款占比；
- 长期借款占比；
- 一年内到期非流动负债；
- 债务期限错配；
- 融资成本；
- 银行贷款增长；
- 抵押/质押贷款占比；
- 保证贷款占比。

治理和披露机制：

- 会计稳健性；
- 坏消息确认及时性；
- 年报风险披露具体性；
- 审计费用；
- 债务类关键审计事项；
- 非标审计意见；
- 审计报告滞后。

## 六、基准模型

主模型采用暴露度 DID / DDD：

```text
Y_i,c,j,t =
  beta PB_c,t x Exposure_i,pre
  + gamma Controls_i,t-1
  + FirmFE_i
  + CityYearFE_c,t
  + IndustryYearFE_j,t
  + epsilon_i,c,j,t
```

其中：

- `i` 是企业；
- `c` 是城市或中级法院辖区；
- `j` 是行业；
- `t` 是年份；
- `Exposure_i,pre` 是政策前企业层面自然人责任暴露；
- `FirmFE_i` 吸收企业不随时间变化的特质；
- `CityYearFE_c,t` 吸收所有城市年份层面的冲击；
- `IndustryYearFE_j,t` 吸收行业周期；
- 标准误聚类在城市或中院辖区层面。

这个模型的识别不是来自城市之间的平均差异，而是来自：

> 同一城市、同一年内，高自然人责任暴露企业与低自然人责任暴露企业在 PB 后的相对变化。

这也是本文区别于普通 PB DID 文献的关键。

### 控制变量

可保留常规企业控制变量：

- Size；
- Lev；
- ROA；
- TobinQ；
- Age；
- Growth；
- CFO；
- IndepRatio；
- Dual；
- Top1Share；
- SOE。

如果主 Y 是崩盘风险，还应补：

- 月/周收益波动；
- 年度平均收益；
- 换手率；
- 分析师覆盖；
- 机构持股；
- 信息透明度代理。

## 七、动态效应和平行趋势

事件研究模型：

```text
Y_i,c,j,t =
  sum_k beta_k EventTime_c,t^k x Exposure_i,pre
  + Controls_i,t-1
  + FirmFE_i
  + CityYearFE_c,t
  + IndustryYearFE_j,t
  + epsilon_i,c,j,t
```

基准期设为 `k = -1`。

建议窗口：

`k <= -4`, `k = -3`, `k = -2`, `k = 0`, `k = +1`, `k >= +2`

核心检查：

- `k = -3` 和 `k = -2` 联合不显著；
- 政策后 `k = +1` 或 `k >= +2` 出现理论一致方向；
- 不把 `k <= -4` 作为唯一否定依据，因为远期 pre-bin 可能混合样本结构。

## 八、为什么不是普通 DID

普通 DID：

```text
Y_i,c,t = beta PB_c,t + FirmFE_i + YearFE_t + ...
```

问题：

- PB 试点城市不是随机的；
- 试点城市往往破产审判基础更好、民营经济更活跃、营商环境改革更多；
- 平均处理效应容易混入城市改革、司法资源、银行生态和创业政策。

本文设计：

```text
PB_c,t x Exposure_i,pre + CityYearFE_c,t
```

优点：

- 不依赖试点城市和非试点城市的平均可比；
- 城市当年所有共同冲击被吸收；
- 只比较同城同年内不同自然人责任暴露企业；
- 更贴合理论，因为 PB 作用对象本来就是自然人，不是所有企业。

## 九、样本和数据

主样本：

- 中国 A 股上市公司；
- 年份暂定 2015-2023 或 2015-2024，视数据可得性；
- 剔除金融业；
- 剔除 ST 或保留并做稳健性；
- 城市匹配优先用主要办公地址，稳健性用注册地址。

政策数据：

- 个人破产条例；
- 个人债务集中清理实施意见；
- 类个人破产司法试点；
- 首案受理或典型案例；
- 中级法院辖区匹配。

企业数据：

- CSMAR/WIND 财务报表；
- CSMAR 股权性质、实际控制人；
- 股权质押；
- 担保公告；
- 年报附注；
- 审计意见、审计费用、关键审计事项；
- 股票周收益构造 NCSKEW/DUVOL。

## 十、识别威胁和处理

### 威胁一：自然人责任暴露不是随机的

高自然人责任暴露企业可能本来风险更高。

处理：

- 使用政策前暴露度；
- 企业固定效应；
- 城市年份固定效应；
- 行业年份固定效应；
- exposure group x year 固定效应；
- 政策前趋势检验；
- SOE placebo。

### 威胁二：PB 试点城市同时推进营商环境改革

处理：

- 城市年份固定效应吸收所有城市年度共同冲击；
- 控制或剔除破产法庭设立、营商环境示范城市、知识产权示范城市等政策；
- 使用同城高低暴露企业比较。

### 威胁三：股价崩盘风险已被相邻文献讨论

处理：

- 不写 `PB -> CrashRisk`；
- 写 `PB x 自然人责任暴露 -> BadNewsHoarding`；
- 把崩盘风险作为坏消息隐藏代理；
- 机制上避开员工财务忧虑和盈余平滑；
- 增加自然人担保、股权质押、控制人失败成本证据。

### 威胁四：信贷收缩可能反向解释主结果

处理：

- 显式提出双机制；
- 区分高失败成本但低债务依赖企业，与高债务依赖企业；
- 检验债务短期化作为反向边界；
- 观察低银行依赖或高现金企业是否更体现坏消息隐藏下降。

## 十一、稳健性设计

政策口径：

- narrow PB；
- broad PB；
- formal PB；
- debt clean-up；
- first-case year；
- month intensity。

暴露度口径：

- 自然人担保金额；
- 自然人担保 dummy；
- 自然人实控；
- 民营 x 自然人实控；
- 股权质押；
- failure cost index；
- high leverage x natural controller。

模型口径：

- 企业 FE + 城市年份 FE + 行业年份 FE；
- 增加 exposure group x year FE；
- 替换为 stacked DID；
- Sun-Abraham / Callaway-Sant'Anna 用于高暴露组动态效应；
- 城市聚类和 wild cluster bootstrap。

样本口径：

- 剔除深圳；
- 剔除浙江；
- 剔除疫情年份；
- 剔除金融和房地产；
- 仅民营企业；
- 仅自然人实控企业；
- 使用办公地址 vs 注册地址。

安慰剂：

- SOE 样本；
- 随机政策年份；
- 随机处理城市；
- 低自然人责任暴露企业；
- 与自然人责任无关的 Y。

## 十二、当前实证试跑对应关系

当前已跑模型：

```text
Y = NCSKEW / DUVOL / short_liab_ratio / AuditFee / InvestIneff 等
X = PB_narrow x natural_pre / failure_cost_pre / high_lev_pre 等
FE = 企业 + 城市年份 + 行业年份
SE = 城市聚类
```

当前最干净结果：

- `PB x natural_pre -> NCSKEW` 为负，前趋势较干净；
- `PB x failure_cost_pre -> NCSKEW/DUVOL` 为负，前趋势较干净；
- `PB x high_lev_pre -> short_liab_ratio` 为正，前趋势较干净；
- `PB x natural_highlev_pre -> short_liab_ratio` 为正，前趋势较干净。

这些结果支持本文的双机制框架：

`自然人失败成本下降 -> 坏消息隐藏下降`

`自然人追偿价值下降 -> 信贷期限控制增强`

## 十三、目前最需要补的数据

第一优先级：

- 自然人为本企业债务提供保证担保的公告或年报附注；
- 实际控制人/控股股东/法定代表人/董监高个人保证；
- 股权质押数据；
- 控制人类型和创始人控制。

第二优先级：

- 审计费用、KAM 文本、非标意见；
- 风险披露文本；
- 会计稳健性和减值计提；
- 债务期限结构细项。

第三优先级：

- 银行贷款担保方式；
- 授信额度；
- 商业信用替代；
- 供应链付款周期。

## 十四、当前决策

不建议把论文做成：

`PB -> 债务短期化`

这个故事太简单，也容易被信贷供给文献压住。

也不建议做成：

`PB -> 股价崩盘风险`

这个主张已经被相邻会计文献触及。

建议做成：

`PB x 自然人责任暴露 -> 坏消息隐藏`

并把债务短期化作为边界机制或反向机制。

论文贡献应写成：

1. 把个人破产制度从城市政策冲击推进到自然人责任边界冲击；
2. 解释个人法制度为何会影响上市公司信息风险；
3. 区分失败容错的治理改善效应和追偿价值下降的信贷收缩效应；
4. 为个人破产制度的资本市场后果提供企业层面的暴露度证据。
