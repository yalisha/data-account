## 二、当前 X 的强弱排序

### 1. 最硬但尚缺

```text
NP_GuaranteeExposure_pre
= 政策前自然人为本企业债务提供保证担保金额 / 有息债务
```

需要的数据字段：

```text
担保人名称
担保人性质
被担保对象
担保金额
担保方式
是否连带责任保证
担保对应债务/借款
```

如果 CSMAR/WIND 可下载，优先找：

```text
上市公司担保公告 / 违规担保 / 关联担保 / 对外担保明细
股权质押明细
控股股东股权质押

```

## 三、今晚已经做的硬化动作

1. 保留控制人性质数据作为 `natural_pre` 的来源；
2. 新增年报全文自然人责任暴露抽取脚本；
3. 小样本测试后发现粗词典误抓严重，已缩窄为更明确的“个人担保 / 连带责任 / 控制人质押 / 司法冻结 / 追偿代偿”口径；
4. 生成时会同时输出 240 条高暴露样本，供人工核验。

## 四、不能过度宣称的地方

`ar_np_liability_text_pre` 不是正式数据库里的担保金额。
它目前只能写成：

```text
基于年报全文的自然人责任暴露文本代理。
```

若主结果只依赖这个变量，文章贡献应降温。
如果后续能补到担保公告金额或股权质押比例，文章层级会明显提高。
