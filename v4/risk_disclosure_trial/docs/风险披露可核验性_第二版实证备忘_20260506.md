## 二、Y 变量构造

### 1. 通用可核验风险披露

```text
risk_verifiability_index
risk_verif_debt_distress_per10k
risk_verif_guarantee_pledge_per10k
risk_verif_legal_process_per10k
```

它们识别风险披露段中金额、期限、责任主体、债务、担保、质押、逾期、诉讼、执行、冻结等可被外部资料交叉验证的表达。

### 2. 自然人责任风险披露

```text
np_liability_verifiability_index
np_liability_control_right_per10k
```

修正缩尾 bug 后，直接自然人责任披露不再全为 0，但它仍然非常稀疏：

```text
np_liability_risk_verif_raw > 0 的样本约 5.15%
np_liability_control_right_per10k > 0 的样本约 0.24%
np_liability_np_guarantee_per10k > 0 的样本约 0.04%
```

这说明“直接自然人责任披露”适合做补充结果或机制拆分，不适合现阶段单独当主 Y。

## 四、第二版主要结果

### 1. 高债务暴露企业的整体可核验披露提高

```text
PB × high_lev_pre -> risk_verifiability_index
```

结果：

```text
主规格：coef = 0.0675, p = 0.0566
严格规格：coef = 0.0642, p = 0.0809
近端前趋势 p = 0.3369
政策后 +1 年：coef = 0.0735, p = 0.0072
政策后 >=+2 年：coef = 0.1596, p = 0.0179
```

解释：

这条目前最像“债务压力 / 追偿风险暴露 -> 风险披露更可核验”的主结果。它稳，但 `high_lev_pre` 不能被写成自然人责任暴露。

### 2. 高债务暴露企业的控制权风险披露增加

```text
PB × high_lev_pre -> np_liability_control_right_per10k
```

结果：

```text
主规格：coef = 0.0932, p = 0.0518
严格规格：coef = 0.1196, p = 0.0768
近端前趋势 p = 0.2092
政策后 +1 年：coef = 0.7706, p = 0.0344
政策后 >=+2 年：coef = 0.8213, p = 0.0250
```

解释：

这是比较有意思的结果。高债务暴露企业在 PB 后更可能披露与股权质押、冻结、平仓、控制权稳定等相关的自然人/控制权风险表达。它可以作为“高债务压力下责任边界变化迫使披露更具体”的证据。

## 五、当前最重要判断

方向可以继续，但故事要诚实收束：

```text
现在最稳的不是“自然人实控企业提高自然人责任披露”，
而是“高债务/控制人质押暴露企业，在个人破产制度冲击后，提高更可核验的债务、担保、质押和控制权风险披露”。
```

目前可写的中期故事是：

```text
个人破产制度改变自然人责任边界和债权追偿预期后，
债务压力较高、控制人质押/冻结风险较高的企业，
会从空泛风险叙事转向更具体、可核验的风险披露，
尤其是债务风险、担保质押风险和控制权风险披露。
```

不能写成：

```text
个人破产制度普遍提高企业风险披露质量。
```

也不能写成：

```text
自然人责任暴露企业一定提高自然人责任披露。
```
