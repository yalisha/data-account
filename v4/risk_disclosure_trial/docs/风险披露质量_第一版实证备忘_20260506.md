## 二、风险披露指标怎么构造

抽取口径偏保守：只识别年报中有明确风险标题的段落，例如：

```text
风险因素
主要风险
公司面临的风险
公司可能面临的风险及应对措施
风险及应对
风险管理
```

为了降低脏数据，已取消“只要段落里出现风险就抓取”的 fallback。因此有些企业会被记为没有明确风险段，但主指标更干净。

主要指标：

```text
has_risk_text             是否识别到明确风险披露段
risk_chars_ln             风险披露长度
risk_specificity_index    风险披露具体性指数
risk_quality_index        综合风险披露质量指数
risk_boilerplate_ratio    模板化风险话语比例
risk_debt_per10k          债务/融资/担保/现金流风险披露密度
risk_category_count       风险类型覆盖广度
```

全量抽取结果：

- 2015-2023 年共 30,496 个 firm-year；
- 覆盖 4,938 家上市公司；
- 明确风险段识别率从 2015 年的 80.0% 上升到 2023 年的 92.1%；
- 平均风险披露字数从 2015 年的 386 字上升到 2023 年的 534 字。

## 三、模型

基准模型：

```text
RiskDisclosure_i,c,j,t =
beta PB_c,t x Exposure_i,pre
+ FirmFE_i + CityYearFE_c,t + IndustryYearFE_j,t
+ Controls_i,t-1 + epsilon_i,c,j,t
```

严格规格：

```text
+ ExposureGroup_i x YearFE_t
```

标准误聚类在城市层面。

当前 exposure 仍是低成本代理：

```text
natural_pre
failure_cost_pre
private_pre
high_lev_pre
natural_highlev_pre
private_highlev_pre
```

注意：`high_lev_pre` 不是自然人责任暴露，只能解释为债务风险 / 融资压力暴露。

## 四、第一版结果

### 1. 最稳信号：高债务暴露企业风险披露更具体

```text
PB x high_lev_pre -> risk_specificity_index
```

结果：

- 主规格系数 0.0781，p = 0.006；
- 加 `ExposureGroup x YearFE` 后系数 0.0737，p = 0.026；
- 近端前趋势 p = 0.845；
- 政策后 +1 年系数 0.0788，p = 0.004；
- 政策后 >=+2 年系数 0.1076，p = 0.046。

```text
PB x high_lev_pre -> risk_quality_index
```

结果：

- 主规格系数 0.0673，p = 0.043；
- 加 `ExposureGroup x YearFE` 后系数 0.0622，p = 0.081；
- 近端前趋势 p = 0.944；
- 政策后 >=+2 年系数 0.1017，p = 0.050。

解释：

这支持“个人破产制度改变责任边界后，债务风险暴露高的企业会提高风险披露具体性”。但这条目前更像债务压力 / 信贷风险披露故事，不是最纯的自然人责任故事。

### 2. 自然人责任暴露有信号，但主要体现在是否披露风险段

```text
PB x natural_pre -> has_risk_text
```

结果：

- 主规格系数 0.0433，p = 0.055；
- 严格规格不稳：系数 0.0164，p = 0.478；
- 近端前趋势 p = 0.651；
- event0 系数 0.0577，p = 0.008；
- +1 年系数 0.0454，p = 0.032。

```text
PB x failure_cost_pre -> has_risk_text
```

结果：

- 主规格系数 0.0760，p = 0.043；
- 严格规格不稳：系数 0.0539，p = 0.140；
- 近端前趋势 p = 0.883；
- event0 系数 0.1093，p < 0.001；
- +1 年系数 0.0791，p < 0.001。

解释：

自然人/失败成本暴露下，PB 后企业更可能出现明确风险披露段。但目前没有稳定推进到“披露质量/具体性”层面，因此不能直接宣称自然人责任边界提高风险披露质量。

### 3. 债务风险披露有滞后反应

```text
PB x failure_cost_pre -> risk_debt_per10k
```

结果：

- 主规格系数 2.7976，p = 0.058；
- 严格规格系数 3.0718，p = 0.040；
- 近端前趋势 p = 0.687；
- 政策后 >=+2 年系数 3.3926，p = 0.017。

```text
PB x high_lev_pre -> risk_debt_per10k
```

结果：

- 主规格系数 1.3637，p = 0.096；
- 严格规格系数 1.4606，p = 0.088；
- 近端前趋势 p = 0.478；
- +1 年系数 1.7804，p = 0.067；
- >=+2 年系数 3.1460，p = 0.004。

解释：

这条符合“追偿价值下降 / 债务压力上升 -> 债务风险披露增加”的机制，但适合作为边界或机制，不宜单独作为主线。

## 五、当前判断

方向有价值，但第一版结果提示主线要稍微调整：

```text
不是简单写：PB x 自然人责任暴露 -> 风险披露质量提高

更稳写法是：
PB 改变自然人责任边界和债权追偿预期，
高责任/债务暴露企业更倾向披露风险；
其中债务暴露高的企业披露更具体、债务风险内容更多。
```

如果坚持最纯的自然人责任边界故事，当前 X 还不够硬。`natural_pre` 和 `failure_cost_pre` 只能推动 `has_risk_text`，对 `risk_quality_index` 和 `risk_specificity_index` 暂时不稳。

如果从实证结果出发，当前最强路径是：

```text
PB x high_lev_pre -> 风险披露具体性 / 风险披露质量
PB x failure_cost_pre -> 债务风险披露密度
PB x natural_pre / failure_cost_pre -> 是否披露风险段
```

## 七、结论

这个方向可以继续，但现在还不能说已经成稿。

最重要的正面信息是：

```text
风险披露文本指标已经可构造；
PB 后高债务暴露企业风险披露具体性提高；
自然人/失败成本暴露企业更可能出现明确风险披露；
债务风险披露在政策后两年更明显。
```

最重要的风险是：

```text
自然人责任暴露代理仍偏软；
最强质量结果来自 high_lev_pre，而不是 natural_pre；
当前风险披露抽取还需要人工校验。
```

因此下一步不应换题，而应补硬 X 和人工校验 Y。
