# 个人破产制度作为 X 的构造速读

日期：2026-05-04

## 结论

个人破产制度最好不要只当成一个泛泛的“法治环境”变量。更好的做法是先明确它代表哪一种制度含义，再构造 X：

1. 失败兜底 / 个人有限责任保护
2. 债权回收风险上升 / 银行信贷供给收缩
3. 员工财务忧虑缓解
4. 创业与创新容错环境改善
5. 个人破产配套治理质量

对会计研究更有潜力的不是裸变量 `PB`，而是：

`PB_city,year x 个人责任暴露_i`

其中“个人责任暴露”可以来自自然人大股东保证担保、民营/创业型企业、个人控制人、股权质押、员工财务压力暴露、银行贷款依赖等。这样比单独说“某地有个人破产制度”更贴近企业行为。

## 3 篇范文怎么用

### 1. 陈怡欣、张俊瑞：个人破产制度与企业盈余平滑

本地文件：`个人破产制度与企业盈余平滑——基于中国个人破产试点的准自然实验_陈怡欣.pdf`

这篇是最接近会计论文的范文。

X 构造：

`PB_i,t = 1`，当企业经营地所在中级人民法院已经出台个人破产制度相关文件，且年份大于制度颁布年份；否则为 0。

样本和设计：

- A 股上市公司，2007-2023 年
- 多时点 DID
- 公司、年份、经营地城市固定效应
- 城市层面聚类稳健标准误

Y：

- 盈余平滑 `ES_TZ`
- 盈余平滑 `ES_LZ`

机制：

- 个人破产制度降低员工陷入个人财务困境时的潜在损失
- 员工财务忧虑下降
- 企业原本通过盈余平滑稳定员工预期的动机减弱

关键借法：

- 它已经把“个人破产制度 -> 企业会计信息披露行为”这条线打出来了。
- 如果继续做盈余平滑，撞题风险很高。
- 值得借的是机制框架：个人破产制度不是直接作用于公司，而是通过员工、自然人大股东、个人保证担保这些自然人主体进入企业决策。

可避开的新 Y：

- 会计稳健性
- 真实盈余管理
- 业绩预告质量
- 内控缺陷披露
- 审计费用 / 审计意见
- 债务契约相关会计选择
- 管理层语调和风险披露

### 2. 纪翔阁等：个人破产制度与信贷资源供给

本地文件：`个人破产制度与信贷资源供给_纪翔阁.pdf`

这篇是“银行侧”范文。

X 构造：

`Bankruptcy_c,t = 1`，城市当年及之后推行个人破产试点；否则为 0。

样本和设计：

- 城市商业银行、农村商业银行，2015-2022 年
- 银行-城市-年份面板
- 银行和年份固定效应
- 城市层面聚类

Y：

- 银行信贷供给水平 `Loan = 贷款余额 / 总资产`

机制：

- 个人破产制度降低债权追偿价值
- 银行预期损失上升
- 银行风险态度更保守
- 信贷供给下降

进一步结果：

- 抵押贷款、质押贷款、短期贷款比重上升
- 信用贷款、保证贷款、中长期贷款下降
- 小规模企业债务融资受限

关键借法：

- 如果我们的企业层面 Y 与融资压力、债务契约、会计选择有关，可以把个人破产制度解释为“外生的信贷供给收缩冲击”。
- 比如构造：`PB_city,year x BankDependence_i`。

可做 X 名称：

- 个人破产引致的信贷收缩
- 债权回收不确定性冲击
- 自然人担保追偿价值下降
- 债务融资约束冲击

### 3. 汤旭东等：个人破产试点促进城市科技创业活跃度提升

本地文件：`个人破产试点促进城市科技创业活跃度提升_汤旭东.pdf`

这篇是“城市创业环境”范文。

X 构造：

`Policy_c,t = 1`，城市在政策实施当年及之后属于个债清理试点；否则为 0。

样本和设计：

- 267 个城市，2015-2022 年
- 城市年度非平衡面板
- 多时点 DID
- 城市和年份固定效应

Y：

- 科技创业活跃度 `Newtech = 当年新创科技企业数 / 当年新创企业总数`

机制：

- 缓解创业失败顾虑
- 优化城市融资环境
- 优化营商环境

异质性：

- 科教质量更高
- 城镇化水平更高
- 要素市场更完善

关键借法：

- 如果做企业创新、风险承担、创业型民企、科创企业，这篇可以作为“失败容错制度环境”的范文。
- 但它偏宏观城市创业，和会计论文的距离比陈怡欣那篇远。

## 可以构造的 X

### X1：个人破产制度试点

定义：

`PB_c,t = 1[城市 c 在年份 t 已实施个人破产 / 个债清理试点]`

适合：

- 做政策冲击本身
- 先跑基准
- 作为后续交互项的制度底座

问题：

- 已有 3 篇都在裸用这个冲击
- 如果 Y 也是常规会计结果，创新不够
- 需要处理多时点 DID 的异质处理效应问题

### X2：个人有限责任保护暴露

定义：

`PB_c,t x PersonalLiabilityExposure_i`

可选暴露变量：

- 企业是否存在自然人大股东个人保证担保
- 控股股东 / 实控人为自然人
- 民营企业
- 股权质押水平
- 企业是否高度依赖银行贷款
- 企业规模小、融资约束高

理论含义：

个人破产制度把企业家、控制人、担保人的失败成本从“无限追偿”部分转为“有限责任保护”。这会改变企业风险承担、融资约束和信息披露激励。

推荐度：最高。

### X3：个人破产引致的信贷收缩暴露

定义：

`PB_c,t x BankDependence_i`

可选暴露变量：

- 银行借款占总资产
- 短期借款占比
- 地方性银行依赖
- 民企 / 小企业 / 高融资约束企业
- 低抵押品企业

理论含义：

个人破产制度提高银行对自然人相关贷款和个人担保贷款的回收风险，银行收紧信贷，企业融资压力上升，进而影响会计选择。

适合的 Y：

- 真实盈余管理
- 会计稳健性
- 审计费用
- 管理层风险披露
- 债务期限结构
- 投资效率

### X4：员工财务安全网冲击

定义：

`PB_c,t x EmployeeExposure_i`

可选暴露变量：

- 员工人数 / 劳动密集度
- 员工平均薪酬较低
- 高技能员工占比
- 研发人员占比
- 职工董事
- 地区居民杠杆率或失信被执行人压力

理论含义：

个人破产制度降低员工陷入个人财务困境后的损失，缓解员工财务忧虑，改变企业稳定员工预期的披露和会计动机。

注意：

陈怡欣那篇已经用这个机制解释了盈余平滑，所以不要再用同一个 Y。

### X5：失败容错型创业环境

定义：

`PB_c,t x InnovationExposure_i`

可选暴露变量：

- 高技术企业
- 科创板 / 创业板
- 高 R&D 强度
- 高无形资产
- 年轻企业
- 民营企业

理论含义：

个人破产制度提供失败兜底，降低企业家和技术创业者的失败成本，提升风险承担和创新投入。

适合的 Y：

- 企业创新
- 风险承担
- 新业务进入
- 高质量专利
- 研发资本化
- 创新披露质量

### X6：个人破产制度执行质量

定义：

`PB_c,t x ImplementationQuality_c,t`

可选执行质量：

- 破产管理人协会
- 网络查控系统使用程度
- 府院联动机制
- 地区信用环境
- 司法支出

理论含义：

个人破产制度是否真正改变市场预期，取决于制度能否被可信执行。执行质量越高，制度效应越强；执行质量不足时，银行可能更担忧逃废债。

## 我建议优先考虑的题目方向

### 方向 A：个人破产制度、自然人担保与企业会计稳健性

核心 X：

`PB_c,t x PersonalGuarantee_i`

逻辑：

个人破产制度降低自然人担保的追偿价值，银行对相关企业的信贷风险更敏感。企业为了维持债权人信任，可能提高会计稳健性；也可能因融资压力上升而更激进地操纵盈余。这个方向可以把正反机制讲清楚，实证上用会计稳健性、审计费用、债务期限或抵押贷款作结果链。

优点：

- 比裸 `PB` 更新
- 直接抓住个人破产制度中“个人责任”这个核心
- 能接会计、审计、债务契约

风险：

- 要拿到自然人担保数据
- 如果只能用民企替代，识别力度会下降

### 方向 B：个人破产制度、银行信贷收缩与企业真实盈余管理

核心 X：

`PB_c,t x BankDependence_i`

逻辑：

个人破产制度提高银行预期损失，压缩信贷供给。高银行依赖企业受到更强融资压力，可能通过真实活动操纵改善短期报表表现，也可能减少长期投入。

优点：

- 能借纪翔阁等的银行侧范文
- 和会计结果结合自然
- 数据相对容易

风险：

- 需要证明冲击是信贷供给而不是地区经济趋势
- 要做足平行趋势和地区趋势控制

### 方向 C：个人破产制度、员工财务安全网与企业披露策略

核心 X：

`PB_c,t x EmployeeExposure_i`

逻辑：

个人破产制度缓解员工财务忧虑后，企业通过会计信息稳定员工预期的动机下降。不要再做盈余平滑，可以转向管理层语调、风险披露、业绩预告、员工相关信息披露。

优点：

- 和陈怡欣那篇高度贴近，写作模板好借
- 机制清楚

风险：

- 盈余平滑已被抢跑
- 换 Y 后需要证明员工能观察并反应企业披露

## 可直接借的写法

### X 构造写法

本文以各地中级人民法院或地方政府出台个人破产、个人债务集中清理等制度文件作为个人破产制度试点的识别依据。若企业经营地所在城市在年份 t 已实施相关试点，则 `PB_c,t` 取值为 1，否则为 0。在此基础上，本文进一步结合企业层面的个人责任暴露，构造 `PB_c,t x Exposure_i`，以识别个人破产制度对受自然人无限责任约束更强企业的差异化影响。

### 理论机制写法

个人破产制度的核心不是简单改善一般法治环境，而是为“诚实而不幸”的自然人提供债务重整、清算和免责安排。对于承担个人连带责任的企业家、担保人和员工而言，该制度降低了经营失败或个人财务困境后的极端损失，改变其风险承担和财务安全预期。与此同时，对银行等债权人而言，个人破产制度也降低了部分债权追偿价值，可能诱发更保守的信贷供给行为。由此，个人破产制度会通过“失败兜底”和“信贷收缩”两条相反力量影响企业会计与投融资决策。

### 实证模型写法

`Y_i,t = beta_0 + beta_1 PB_c,t x Exposure_i + beta_2 PB_c,t + beta_3 Exposure_i + Controls_i,t + FirmFE + YearFE + CityFE + epsilon_i,t`

如果 `Exposure_i` 是不随时间变化的变量，在公司固定效应下会被吸收，可以只保留交互项和控制变量。

## 操作提醒

1. 政策时点要按城市 / 中级人民法院辖区手工核对，不能只用省份。
2. “个人债务集中清理”“与个人破产功能相当试点”“深圳个人破产条例”可以先统一为个人破产试点，后续做拆分稳健性。
3. 多时点 DID 要做事件研究、Goodman-Bacon 分解或 Sun-Abraham / Callaway-Sant'Anna 稳健性。
4. 不建议再选“个人破产制度 -> 盈余平滑”，这条已被陈怡欣、张俊瑞基本占住。
5. 最推荐从“个人破产制度 x 自然人责任暴露”切入，这才是制度和企业会计行为之间最紧的连接点。

## 2026-05-04 更新：崩盘风险方向的实证与新颖性判断

### 全量候选 Y 试跑后的结果

基于现有 `v1` 样本和快速政策表，已重跑崩盘风险、应计质量、审计风险、债务压力、投资效率和供应链变量。统一模型为：

`Y_i,c,t = beta PB_c,t x Exposure_i,pre + FirmFE_i + CityYearFE_c,t + IndustryYearFE_j,t + Controls_i,t-1 + epsilon_i,c,t`

其中 `PB_c,t` 使用 narrow 政策表，`Exposure_i,pre` 使用政策前民营、自然人控制、高杠杆、自然人高杠杆、失败成本暴露等代理。

当前最干净的正面政策效应是：

- `PB x natural_pre -> NCSKEW`：系数 -0.1333，p < 0.001；前趋势 p = 0.579。
- `PB x failure_cost_pre -> NCSKEW`：系数 -0.1691，p < 0.001；前趋势 p = 0.425。
- `PB x failure_cost_pre -> DUVOL`：系数 -0.0767，p = 0.002；前趋势 p = 0.152。

债务短期化也比较稳：

- `PB x high_lev_pre -> short_liab_ratio`：系数 0.0265，p = 0.007；前趋势 p = 0.285。
- `PB x private_highlev_pre -> short_liab_ratio`：系数 0.0387，p = 0.004；前趋势 p = 0.256。
- `PB x natural_highlev_pre -> short_liab_ratio`：系数 0.0356，p = 0.011；前趋势 p = 0.217。

### 新颖性警戒

崩盘风险不是完全空白。陈怡欣、张俊瑞（2026，《会计研究》）主文研究“个人破产制度与企业盈余平滑”，但进一步分析已经包含股价崩盘风险。他们的逻辑是：

`个人破产制度 -> 员工财务忧虑缓解 -> 机会主义盈余平滑下降 -> 股价崩盘风险缓解`

因此，不能再写成简单的：

`个人破产制度 -> 股价崩盘风险`

更可行的差异化是：

`个人破产制度 x 自然人责任暴露 -> 控制人坏消息隐藏 -> 股价崩盘风险`

并进一步区分：

- 失败容错效应：自然人控制 / 失败成本暴露企业的崩盘风险下降。
- 信贷收缩效应：高杠杆企业的崩盘风险可能上升，债务期限短期化作为机制证据。

### 更新后的优先级

1. **首选但需重构贡献**：自然人责任边界、坏消息隐藏与股价崩盘风险。
2. **机制 / 并列补充**：债务期限短期化。
3. **不建议主打**：审计风险、投资效率、杠杆下降、供应链集中度。
