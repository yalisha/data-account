# 自然人责任边界与企业风险披露可核验性：研究设计冻结版

日期：2026-05-06

## 一、当前冻结题目

```text
自然人责任边界与企业风险披露可核验性：来自个人破产制度试点的证据
```

这个版本不再以股价崩盘风险、债务期限结构、审计费用、创新或会计稳健性作为主 Y。
这些变量后续最多作为机制、边界或经济后果。

## 二、研究问题

当本地个人破产制度或个人债务集中清理机制出现后，原先企业风险与自然人风险高度绑定的企业，是否会改变年报风险披露方式，减少空泛、模板化风险叙事，增加更具体、可外部核验的责任风险、债务风险、担保风险、诉讼执行风险、质押风险和偿债安排表达？

一句话：

```text
个人破产制度改变自然人责任边界后，高自然人责任暴露企业是否提高风险披露的可核验性。
```

## 三、理论定位

本文不把个人破产制度理解成一般城市营商环境政策，而是理解成自然人责任边界冲击。

企业受到影响，不是因为上市公司本身可以适用个人破产制度，而是因为企业背后的自然人主体可能承担企业失败后的个人担保、连带责任、追偿压力、股权质押平仓风险、信用惩戒和控制权损失。

可以靠近的既有概念：

```text
business-personal risk non-separation
personal guarantee / owner guarantee
contracting out of limited liability
entrepreneurial downside risk / failure cost
personal recourse exposure
```

中文表述建议：

```text
借鉴 business-personal risk non-separation、personal guarantee 和 limited liability 文献，
本文将企业债务风险通过自然人担保、控制人个人连带责任和股权质押等安排传导至自然人主体的程度，
定义为企业政策前自然人责任暴露。
```

## 四、核心 DID 结构

主模型：

```text
RiskDisclosureVerifiability_i,c,j,t
= beta PB_c,t × NP_LiabilityExposure_i,pre
+ FirmFE_i + CityYearFE_c,t + IndustryYearFE_j,t
+ Controls_i,t-1 + epsilon_i,c,j,t
```

严格规格：

```text
+ ExposureGroup_i × YearFE_t
```

识别含义：

```text
同一城市、同一年内，政策实施后自然人责任暴露更高的企业，
相对于低暴露企业，风险披露可核验性是否提高。
```

这个设计不识别城市 PB 的平均效应。`CityYearFE` 会吸收城市当年的所有共同冲击，包括营商环境、法院资源、地方金融环境和疫情冲击。识别来自企业政策前暴露度的差异。

## 五、X 的层级

### 1. 最硬 X

```text
NP_GuaranteeExposure_i,pre
= 政策前自然人为本企业债务提供保证担保金额 / 政策前有息债务
```

自然人包括实际控制人、控股股东中的自然人、法定代表人、董事长、总经理、董监高、自然人股东、配偶或亲属。

这是最能支撑“自然人责任边界”的变量。

### 2. 次硬 X

```text
NP_GuaranteeDummy_i,pre
ControllerPledgeRatio_i,pre
NaturalController_i,pre × ControllerPledge_i,pre
NaturalController_i,pre × BankDebtDependence_i,pre
NaturalController_i,pre × HighLeverage_i,pre
```

### 3. 当前临时 X

```text
natural_pre
failure_cost_pre
high_lev_pre
natural_highlev_pre
private_highlev_pre
```

注意：

```text
high_lev_pre 不是自然人责任暴露，只能解释为债务风险 / 追偿压力暴露。
natural_pre 和 failure_cost_pre 是低成本代理，不能单独支撑高贡献文章。
```

## 六、Y 的层级

### 主 Y：风险披露可核验性

```text
risk_verifiability_index
risk_verif_per10k
risk_verif_legal_process_per10k
risk_verif_guarantee_pledge_per10k
risk_verif_debt_distress_per10k
```

这些指标刻画风险段中是否出现金额、期限、责任主体、债务、担保、质押、逾期、诉讼、执行、冻结等可被外部资料交叉验证的表达。

### 更贴自然人责任边界的主 Y

```text
np_liability_verifiability_index
np_liability_risk_verif_per10k
np_liability_np_actor_per10k
np_liability_np_guarantee_per10k
np_liability_recourse_capacity_per10k
np_liability_control_right_per10k
```

这些指标直接识别实际控制人、控股股东、法定代表人、自然人股东、个人担保、连带责任、追偿、代偿、股权质押、平仓、控制权变更、司法冻结等表达。

### 对照 Y

```text
has_risk_text
risk_chars_ln
risk_specificity_index
risk_quality_index
risk_boilerplate_ratio
risk_debt_per10k
```

这些可以说明披露存在、披露长度、一般具体性和债务风险披露，但不应替代“可核验性”主 Y。

## 七、假说

H1：

```text
个人破产制度实施后，政策前自然人责任暴露越高的企业，风险披露可核验性越高。
```

H2：

```text
H1 在自然人担保、自然人实控、控制人股权质押、个人连带责任更强的企业中更明显。
```

H3：

```text
若企业高度依赖自然人追偿价值或银行债务，个人破产制度可能同时引发债权人风险重估，
表现为债务风险、担保质押、诉讼执行和偿债安排相关披露增加。
```

## 八、机制变量和边界变量

机制不再写成一堆小 Y，而按证据链放置：

```text
PB × 自然人责任暴露 -> 可核验风险披露提高
PB × 自然人责任暴露 -> 模板化风险披露下降
PB × 债务/担保暴露 -> 债务风险披露、担保质押披露、诉讼执行披露增加
```

债务期限结构、融资成本、审计费用、非标意见、KAM、会计稳健性、减值确认和股价崩盘风险都暂不当主 Y。

## 九、现阶段证据

已有第一版结果显示：

```text
PB × high_lev_pre -> risk_specificity_index
```

在主规格和加入 `ExposureGroup × YearFE` 后均有信号，近端前趋势较干净。

```text
PB × failure_cost_pre -> risk_debt_per10k
```

严格规格下有信号，政策后两年债务风险披露上升。

```text
PB × natural_pre / failure_cost_pre -> has_risk_text
```

动态上有反应，但严格趋势控制后不稳。

当前判断：

```text
风险披露方向可以继续；
但最强信号暂时来自债务暴露，不是自然人责任暴露；
必须补自然人担保、个人连带保证和股权质押等硬 X。
```

## 十、下一步执行顺序

1. 构造 `risk_verifiability_index` 和 `np_liability_verifiability_index`；
2. 抽样核验风险披露段，确认不是财报附注、金融工具风险管理或公司治理段误抓；
3. 用当前临时 X 复跑可核验披露 Y，判断方向是否值得继续；
4. 补自然人担保和股权质押 X；
5. 用硬 X 复跑主模型、事件研究、剔除深圳/浙江/疫情年份、wild cluster bootstrap；
6. 再决定是否把债务期限、审计风险、会计确认或崩盘风险作为机制/后果放入论文。

## 十一、对合作老师的一段话

```text
我们现在把题目从“个人破产制度影响企业某个结果变量”收束为
“自然人责任边界与企业风险披露可核验性”。
理论上借鉴 business-personal risk non-separation、personal guarantee 和 limited liability 文献，
把自然人担保、控制人个人连带责任、自然人实控和控制人股权质押理解为企业政策前自然人责任暴露。
识别上采用城市个人破产/个债清理试点 × 企业政策前自然人责任暴露的 difference-in-exposure DID，
并加入企业固定效应、城市年份固定效应和行业年份固定效应。
这样比较的是同一城市同一年内高低自然人责任暴露企业的披露变化，
不是试点城市和非试点城市的简单平均差异。
主 Y 不再是股价崩盘风险，而是风险披露中可被外部资料核验的责任主体、债务追偿、担保质押、诉讼执行、逾期违约和偿债安排表达。
```
