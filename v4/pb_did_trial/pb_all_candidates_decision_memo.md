# 个人破产制度候选 Y 全量重跑决策备忘

日期：2026-05-04

## 总判断

当前最值得继续的是 A 线的正面政策效应，但不能简单写成“个人破产制度降低股价崩盘风险”。最新检索发现，陈怡欣、张俊瑞（2026，《会计研究》）虽以盈余平滑为主 Y，但已经在进一步分析中报告“个人破产制度通过减少机会主义属性盈余平滑，进而缓解股价崩盘风险”。因此，崩盘风险方向不是完全空白。

若继续做，贡献必须从“PB -> CrashRisk”改为：

> 个人破产制度如何通过自然人责任边界变化，改变控制人的坏消息隐藏动机；并区分“失败容错降低坏消息隐藏”和“信贷收缩/风险转移加剧崩盘风险”两条竞争机制。

更具体地，主识别应使用 `PB x natural_pre`、`PB x failure_cost_pre`、`PB x natural-person guarantee exposure`，而不是裸 `PB`。

## 仍然值得继续的理由

尽管相邻文献已经触及股价崩盘风险，但我们仍有三个可区分点：

1. 陈怡欣、张俊瑞的主线是“员工财务忧虑 -> 盈余平滑 -> 崩盘风险”，崩盘风险是经济后果；我们的主线应是“企业家/自然人控制人失败成本 -> 坏消息隐藏 -> 崩盘风险”。
2. 他们的核心处理变量是城市层面 `PB`，我们的核心处理应是 `PB x 自然人责任暴露`，并用城市年份固定效应吸收全部城市层面同期冲击。
3. 我们的结果显示自然人控制/失败成本暴露下崩盘风险下降，但高杠杆暴露下崩盘风险上升，可以写成制度正面效应与信贷收缩副作用并存的双机制，而不是单向平均效应。

## 最新检索红线

- 西北大学经济管理学院官网新闻确认：陈怡欣、张俊瑞《个人破产制度与企业盈余平滑——基于中国个人破产试点的准自然实验》已发表于《会计研究》2026年第2期，并说明该文发现个人破产制度减少机会主义属性盈余平滑，进而缓解股价崩盘风险。
- 中国会计学会《会计研究》2026年第2期目录确认该文已出现在当期目录。
- 本地 PDF 抽取也显示该文摘要、引言、进一步分析和结论均提到股价崩盘风险；第 13 页左右还给出 NCSKEW、DUVOL 的构造和“个人破产制度抑制企业股价崩盘风险”的表述。

结论：`PB -> 崩盘风险` 不能作为新颖主张；`PB x 自然人责任暴露 -> 崩盘风险` 仍可作为有条件可做方向。

## 实证重跑后的候选主线

> 个人破产制度降低企业家失败后的毁灭性后果，缓解控制人隐瞒坏消息和强撑风险的动机，从而降低股价崩盘风险。

它比“债务短期化”更有故事，也更容易写成政策正面效果。B 线的债务短期化仍然稳，但更适合作为机制或并列补充，不宜单独扛完整论文。

## 第一梯队：有条件继续

### A1. 坏消息隐藏 / 股价崩盘风险下降

最干净结果：

- `PB x natural_pre -> NCSKEW`：系数 -0.1333，p < 0.001；前趋势 p = 0.579；政策后 +1 和 >=+2 显著为负。
- `PB x failure_cost_pre -> NCSKEW`：系数 -0.1691，p < 0.001；前趋势 p = 0.425；政策后 >=+2 显著为负。
- `PB x failure_cost_pre -> DUVOL`：系数 -0.0767，p = 0.002；前趋势 p = 0.152；政策后 +1 和 >=+2 显著为负。

注意：高杠杆暴露下 `NCSKEW/DUVOL` 方向为正，这提示存在“失败容错降低坏消息隐藏”和“信贷收缩/风险转移增加崩盘风险”两股力量。正式论文应主打自然人控制和失败成本暴露，而不是高杠杆暴露。这个双机制也是绕开陈怡欣、张俊瑞（2026）的关键。

### B1. 债务期限短期化

最干净结果：

- `PB x high_lev_pre -> short_liab_ratio`：系数 0.0265，p = 0.007；前趋势 p = 0.285；政策后 0、+1、>=+2 均为正。
- `PB x private_highlev_pre -> short_liab_ratio`：系数 0.0387，p = 0.004；前趋势 p = 0.256；政策后 0 和 >=+2 为正。
- `PB x natural_highlev_pre -> short_liab_ratio`：系数 0.0356，p = 0.011；前趋势 p = 0.217；政策后 >=+2 为正。

这个结果可以作为机制：银行用更短期限的债务安排替代自然人追偿保护。

## 推荐主故事

题目不能直接定为“个人破产制度与股价崩盘风险”。更好的暂定题目是：

> 自然人责任边界与坏消息隐藏：来自个人破产制度试点的证据

备选：

> 失败容错还是信贷收缩？个人破产制度与企业股价崩盘风险

主线：

个人破产制度明确自然人责任边界，降低企业家失败后的个人毁灭性后果。对自然人控制和失败成本暴露更高的企业而言，控制人隐瞒坏消息、拖延风险释放和强撑股价的动机下降，资本市场中的坏消息积累减少，最终表现为股价崩盘风险下降。与此同时，对高杠杆企业而言，个人追偿价值下降可能引发银行信贷收缩和期限控制，反而加大短期风险压力。文章应解释这两种力量为何在不同暴露企业中方向相反。

机制和异质性：

- 机制一：债务期限短期化，说明债权人治理从事后自然人追偿转向事前期限控制。
- 机制二：在自然人控制、民营、失败成本暴露高的企业中效果更强。
- 反向机制：高杠杆企业可能因信贷收缩而风险上升，应作为竞争性机制处理。
