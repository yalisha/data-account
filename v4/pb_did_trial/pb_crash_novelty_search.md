# 个人破产制度与股价崩盘风险：新颖性检索记录

日期：2026-05-04

## 检索结论

不是完全空白。

目前没有检索到题名直接叫“个人破产制度与股价崩盘风险”的论文，但陈怡欣、张俊瑞（2026，《会计研究》）已经在《个人破产制度与企业盈余平滑——基于中国个人破产试点的准自然实验》中把股价崩盘风险作为进一步分析 / 经济后果处理。

因此，若只写：

> 个人破产制度降低企业股价崩盘风险

新颖性不够。

更可行的差异化写法是：

> 个人破产制度通过改变自然人责任边界，影响自然人控制人和高失败成本暴露企业的坏消息隐藏行为；同时，制度也可能通过削弱自然人追偿价值引发信贷收缩，对高杠杆企业形成相反风险压力。

### 陈怡欣、张俊瑞（2026）

题名：个人破产制度与企业盈余平滑——基于中国个人破产试点的准自然实验

期刊：《会计研究》2026 年第 2 期。

核心关系：

- 主 Y：企业盈余平滑。
- 机制：员工财务忧虑。
- 进一步分析：机会主义属性盈余平滑与股价崩盘风险。

本地 PDF 证据：

- 摘要和关键词已经出现“股价崩盘风险”。
- 正文进一步分析部分构造 `NCSKEW` 和 `DUVOL`。
- 结论表述为个人破产制度通过减少机会主义属性盈余平滑，使企业股价崩盘风险得到缓解。

与我们当前想法的关系：

| 维度 | 陈怡欣、张俊瑞（2026） | 当前可做版本 |
|---|---|---|
| 主 Y | 盈余平滑 | 股价崩盘风险 / 坏消息隐藏 |
| 崩盘风险地位 | 经济后果 / 进一步分析 | 主结果 |
| 机制 | 员工财务忧虑 -> 盈余平滑 | 自然人控制人失败成本 -> 坏消息隐藏 |
| X 构造 | 城市层面 PB | `PB x 自然人责任暴露` |
| 固定效应潜力 | 常规 DID | 可用城市年份 FE 做同城同年高低暴露对比 |
| 贡献风险 | 已占住 PB -> 盈余平滑 -> 崩盘风险 | 必须强调责任边界、控制人激励和双机制 |

判断：

这是“强相邻”，不是完全撞题。若没有自然人责任暴露和双机制，容易被认为只是把他们的进一步分析拿出来做主 Y。

## 推荐的新颖性边界

### 不建议写

不建议写成：

> 个人破产制度是否影响股价崩盘风险？

原因：太接近陈怡欣、张俊瑞（2026）的进一步分析。

### 建议写

建议写成：

> 自然人责任边界、控制人坏消息隐藏与股价崩盘风险。

或：

> 失败容错还是信贷收缩？个人破产制度与企业股价崩盘风险。

核心识别必须是：

`PB_c,t x NaturalController_i,pre`

`PB_c,t x FailureCostExposure_i,pre`

`PB_c,t x NaturalGuaranteeExposure_i,pre`

而不是单独的 `PB_c,t`。
