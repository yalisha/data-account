背景：

我们原本考虑研究中国个人破产制度试点对企业结果变量的影响。已有强相邻文献包括：

- 陈怡欣、张俊瑞（2026，《会计研究》）：个人破产制度与企业盈余平滑，并进一步分析股价崩盘风险；
- 纪翔阁等：个人破产制度与信贷资源供给；
- 汤旭东等：个人破产试点促进城市科技创业活跃度；
- 英文文献中也有 personal bankruptcy laws and corporate policies、debtor rights and innovation、fresh start and entrepreneurship、personal guarantees 等相邻研究。

我们目前想把研究问题收窄为：

“个人破产制度改变自然人责任边界后，企业背后的自然人控制人、自然人保证人、自然人股东是否改变其坏消息隐藏、信息风险、审计/披露或财务报告行为。”

当前核心设计不是普通 DID，而是暴露度 DID / DDD：

```text
Y_i,c,j,t =
beta PB_c,t x NaturalPersonLiabilityExposure_i,pre
+ Controls_i,t-1
+ FirmFE_i
+ CityYearFE_c,t
+ IndustryYearFE_j,t
+ epsilon_i,c,j,t
```

其中 `PB_city,t` 是城市/法院辖区层面的个人破产制度、个人债务集中清理或类个人破产试点；`Exposure` 是政策前企业层面的自然人责任暴露。

当前试跑代理包括：

- `natural_pre`：政策前是否自然人实控；
- `high_lev_pre`：政策前杠杆是否高；
- `natural_highlev_pre`；
- `failure_cost_pre = 民营 + 自然人实控 + 创始人控制 + 高杠杆` 的指数。

目前跑得比较好的结果：

- `PB x natural_pre -> NCSKEW` 显著下降，前趋势较干净；
- `PB x failure_cost_pre -> NCSKEW/DUVOL` 显著下降，前趋势较干净；
- `PB x high_lev_pre -> short_liab_ratio` 显著上升，前趋势较干净；
- `PB x natural_highlev_pre -> short_liab_ratio` 显著上升，前趋势较干净。

我们现在担心：
