# 上传说明

这一文件夹用于上传给 ChatGPT Pro，请同时上传全部文件。

## 文件清单

- `chatgpt_pro_prompt.md`：直接复制给 ChatGPT Pro 的完整 prompt。
- `research_design_个人破产制度_v1.md`：当前研究设计。
- `个人破产制度文献综述_v2.xlsx`：文献综述工作簿。
- `个人破产制度下载文献初筛报告.md`：Scopus 和知网下载文献初筛结果。
- `个人破产制度文献综述_选题地图.md`：选题地图与撞题判断。

## 使用方式

1. 上传本文件夹内除 README 外的全部材料。
2. 打开 `chatgpt_pro_prompt.md`，复制全文作为对话请求。
3. 要求 ChatGPT Pro 必须基于上传文件判断，不要泛泛回答。
