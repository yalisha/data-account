# VSI 新 Y 试跑结果

日期：2026-04-30

## 构造口径

- `AbsorbRatio60 = PEAD60_abs / (EA_absCAR02 + 1e-6)`，1%/99% winsorize。
- `AbsorbLogRatio60 = log((PEAD60_abs + 1e-4)/(EA_absCAR02 + 1e-4))`，作为比例口径的稳健版本。
- `AbsorbShare60 = PEAD60_abs / (PEAD60_abs + EA_absCAR02)`，表示公告后残余调整占即时反应与残余调整之和的比例。
- `ICOE_PEG = sqrt((FEPS2 - FEPS1) / Price)`，其中 `FEPS1/FEPS2` 为同一自然年内分析师对下一年和下两年 EPS 的最新预测中位数，`Price` 为年末收盘价。
- `ICOE_EY = FEPS1 / Price`，作为覆盖更高的预期盈利收益率补充口径。
- 回归沿用既有口径：`Y_t = L.DU + controls + firm FE + year FE`，聚类到 `IndYear_num`。
- 判读以 `DU_kw` 为主测度；`DU_llm` 是内部语义增强构造，保留展示但不作为新 Y 的否决 gate。
- 回归已用 Stata MCP / `reghdfe` 复跑验证；Stata 结果导出到 `vsi_new_y_reg_results_stata.csv`，与 Python `pyfixest` 结果一致。

## 初步判断

- `AnnouncementAbsorptionRatio` 三个比例口径都没有过关，不能替代 `PEAD60_abs`。
- 按 `DU_kw` 主测度判读，`ImpliedCostOfEquity` 可以进入候选：`ICOE_PEG` 和 `ICOE_EY` 都显著为负。
- `ICOE_EY` 覆盖更高、显著更强；`ICOE_PEG` 理论上更接近隐含权益资本成本，但样本略小。
- `DU_llm` 不作为否决项；可在附录中报告为内部语义增强测度的敏感性检验。
- `PEAD60_abs` 和 `CS_Spread` 保留为对照，便于判断新增变量是否真的超过既有 v3 候选。

## DU_kw 主测度下的排序

1. `PEAD60_abs`：仍是最稳的新主 Y 候选，样本大、事件解释清楚。
2. `ICOE_EY`：新候选中最值得继续推进，`DU_kw` 系数为负且 5% 显著，经济含义是数据要素披露降低投资者要求回报/预期资本成本。
3. `ICOE_PEG`：理论标签更强，但覆盖样本小于 `ICOE_EY`，可作为 CoE 稳健口径。
4. `CS_Spread`：`DU_kw` 约 10% 边际，适合做交易摩擦补充。
5. `AnnouncementAbsorptionRatio`：三个口径均不支持，暂不推进。
