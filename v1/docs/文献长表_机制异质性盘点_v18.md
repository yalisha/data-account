## 六、仅从文献盘点得到的初步观察

### 1. 已经明显拥挤的写法

- `分析师`
- `信息透明度/信息披露质量`
- `融资约束`
- `国企/非国企`
- `企业规模`
- `高科技/技术密集行业`

这些不是不能做，而是别人已经做得很多，继续用时需要更细的变量定义，或者更强的识别设计。

### 2. 近两年开始变细的写法

- `分析师覆盖` 往 `预测分歧/预测准确性` 细化
- `一般披露` 往 `可验证性/可理解性/真实性/异常语调` 细化
- `所有制/规模` 往 `环境不确定性/区域数字基础设施/数据流通条件/外部保障` 细化
- `数据资产` 往 `自用型 vs 交易型`、`integration vs innovation` 细化

### 3. 以后做验证时最值得单独留意的“文献已出现但还没烂大街”的方向

- `披露真实性/夸大披露`
- `可验证性/可理解性`
- `区域数字基础设施/数据流通环境`
- `环境不确定性`
- `分析师预测质量` 而不是单纯分析师数量
- `数据资产类型` 或 `数字化叙事类型`

## 十二、建议的验证顺序

### A层：先做“现成变量”

机制先从：

1. `Analyst`
2. `InstHold` 或 `Big4` 这类最直接代理
3. `Amihud/Turnover` 这类交易层变量

异质性先从：

1. `SOE`
2. `Size`
3. `Hhi`
4. `InstHold`
5. `ProvDigital2016`
6. `Market`

这层的目标不是追求创新，而是最低成本把“文献里高频写法”先对一遍。

### B层：再做“可恢复变量”

机制重点转向：

1. `ForecastDisp`
2. `FcstAcc / FcstAcc_ST / FcstAcc_LT`
3. `InvestIneff`
4. `RetAutoCorr`
5. `AuditFee`
6. `absDA`

异质性重点转向：

1. `SA`
2. `HighTech`
3. `Post2020 / Post2024`
4. `InstStable`

这层最关键，因为它最可能在不补外部数据的前提下，把文献里已经出现过但没那么老套的项补齐。

### C层：最后再碰“文本代理/重构类”

1. `真实性/夸大披露`
2. `可验证性/可理解性`
3. `自用型 vs 交易型`
4. `分析师能力/信息资源`
5. `市场地位`

这层不是不能做，而是定义成本高、口径争议大，应该放在 A、B 两层跑完之后。

### D层：目前先不要动

1. `媒体关注`
2. `内控质量`
3. `标准披露评级`
4. `环境不确定性`
5. `标准创新指标`

这些都涉及外部新数据。除非前面三层已经跑完并且仍然不够，否则暂时不值得先开新战线。

### 小结

1. `2023年后` 并不是没有文献，反而已经足够支撑我们把机制写得更“近年化”。
2. 真正最能回应“太老”的，不是把经典变量全部换掉，而是把引文锚点换成 `2024-2026` 的近年写法。
3. 从这组文献看，最容易保住且不显得过时的机制组合，仍然是：
   `Analyst（辅助） + ForecastDisp/FcstAcc（主） + InvestIneff（主）`。
4. `AuditFee` 也有近年文献，但它在近年文献里更多还是“数字化影响审计成本/风险”的延伸话题，不像 `ForecastDisp/FcstAcc/InvestIneff` 那么适合扛主创新。

## 十四、跳出旧文献池的新概念交叉候选

如果不再沿着“传统机制/传统异质性”往下堆，下一步最值得做的不是追更细碎的旧变量，而是引入 `2024-2026` 年政策与产业语境里更热、但仍能用现有数据落地的新概念。

判断标准只有三个：

1. 概念必须是 `2024-2026` 仍在升温的政策/产业关键词；
2. 概念必须能在当前样本上形成比较干净的企业层或地区层划分；
3. 概念必须和 `DU` 有明确交叉逻辑，而不是纯追热点。

### 1. 现在就能做，而且最值得优先做

| 概念 | 当前热度依据 | 当前数据是否能做 | 具体落地方式 | 评价 |
| --- | --- | --- | --- | --- |

### 3. 现在先不要碰

| 概念 | 为什么暂时不建议 |
| --- | --- |
| `低空经济` | 虽然自 `2024-04-02` 起已写入政府工作报告语境，但当前样本没有标准企业标签，靠行业码很难干净识别 |
| `工业母机` | `2025-09-08` 已有专门标准体系文件，但企业识别需要更细产品或业务口径，现有两位行业码太粗 |
| `新型显示` | 一般需要更细分子行业或主营业务文本，现有口径容易混进整个 `C39` |
| `先进通信` | 容易和普通通信设备、运营商服务混在一起，口径不纯 |
| `新材料` | 概念热，但跨多个行业，若没有外部名录会非常主观 |
| `关键农机` | 可以想象，但样本规模和识别精度都未必够 |
| `装备现代化` | 更像政策口号，不像可直接落地的清晰分组变量 |

### 4. 就当前仓库而言，真正应该优先尝试的三条

1. `StrategicEmerging`
2. `DigEconCore`
3. `IndustryCluster` 或连续型 `LQ`

理由很简单：

- 这三条都已经可以用当前数据构造，不需要额外补大批外部数据；
- 它们都比 `SOE / Size / Analyst high-low` 这类传统异质性更“近年化”；
- 它们不是空泛热词，而是可以和“数据要素利用为什么更能提升定价效率”形成明确交叉逻辑。
