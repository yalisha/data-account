## 一、直接判断

当前成稿 `v11` 的主问题不是主效应弱，而是“机制 + 异质性”的组合太像常规模板：

- 机制仍是 `分析师覆盖 + 流动性(Amihud) + 波动率`
- 异质性仍是 `分析师高低 + 国企/民企 + 股东分散`

这套写法在 2024-2026 年同主题文献里已经非常常见，审稿人会自然把它归类为“又一篇数字化/数据披露改善信息环境”的标准扩展。

## 五、建议的 v17 重构方案

### 方案 A：最稳的重构

#### 主机制

1. `ForecastDisp` 分析师预测分歧
2. `Analyst` 分析师覆盖
3. `InvestIneff` 投资效率偏离

说明：

- 第一条回答“信息处理质量”
- 第二条回答“信息中介数量”
- 第三条回答“实体经营可定价性”

这样比 `Analyst + Amihud + RetVol` 明显更完整，也更不老套。

#### 主异质性

1. `Roastd` 高估值不确定性/高盈利波动
2. `Post2020` 或制度成熟期（建议作为补充）
3. `ShareholderNum` 股东分散度（保留时注明主要由 `DU_llm` 支持）

### 方案 B：如果你必须保留一条传统维度

可以保留 `股东分散度`，但不要再同时保留 `SOE + 分析师高低` 两条。否则整张异质性表会再次回到常规审稿印象。

## 六、对当前 v11 的建议删改

### 建议保留但降级

- `Analyst` 渠道：保留，但不要再单独扛“核心创新”
- `股东分散度`：可保留为补充异质性

### 建议补进主文

- `ForecastDisp`
- `InvestIneff`
- `Roastd`

## 七、下一步执行顺序

1. 先把主机制表改成 `ForecastDisp + Analyst + InvestIneff`
2. 再把异质性表改成 `Roastd + ShareholderNum + Post2020(或附表)`
3. 最后重写引言和贡献，明确与“数据资产披露/数字化转型”文献的差别不是“变量换个名字”，而是：
   - 关注 `实际利用` 而非 `披露`
   - 用 `语义深度` 而非单纯关键词频次
   - 将机制推进到 `预测分歧 / 投资效率 / 不确定性调节`

## 八、一句话结论

如果继续沿着 v11 的 `分析师 + 流动性 + 波动率` 和 `分析师/国企/股东分散` 往前推，审稿意见大概率还会是“异质性和渠道太旧”。  
最可行的办法不是硬辩，而是直接换成仓库里已经有结果支撑、且文献竞争更不拥挤的那一组。
