RED FLAG 1: PSM IMPLEMENTATION METHODOLOGICALLY UNSOUND (CRITICAL)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Issue: PSM matched sample size = 43,804 vs baseline = 43,847
       Only 43 obs (0.1%) removed → defeats the purpose of matching

Root Cause:
- Median split creates ~50-50 treated/control groups (~22k each)
- 1:1 nearest neighbor matching WITHOUT CALIPER applied
- Result: ~44k obs matched (almost entire sample)

Problem:
- PSM is meant to reduce selection bias by restricting sample
- Keeping 99.9% of original sample provides minimal bias reduction
- Contradicts the methodological intent of PSM

Impact Assessment:
- Numerical results are still valid (coef = -0.003898, highly significant)
- But the TEST ITSELF is methodologically unsound
- Similar result to baseline (-0.004157) suggests selection bias is NOT major

Recommendation (Choose One):
Option A: Add Caliper [PREFERRED]
  caliper = 0.25 * pscore.std()
  Keep only matches within caliper distance
  Expected result: ~20k-30k obs (50-70% of sample)

Option B: Alternative Strategy
  Use sample splitting (don't match, just analyze top/bottom quartiles separately)
  Or use 1:N matching with replacement

Status: REQUIRES ATTENTION before final submission
